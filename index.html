Annona — execution kernel for AI agents Star00

Open source · Apache-2.0 · Python · 2026

A sovereign execution kernel: it decides where each step of an agent runs, enforces that decision, and records it. The point is control and auditability — knowing that a step touching sensitive data ran where it was allowed to, and being able to prove it afterwards.

It grew out of a concrete problem. Agent frameworks will happily send anything anywhere, which is a non-starter the moment you handle clinical or regulated data.

Firmware, IoT and the physical layer

Tecniplast & Akaion · 2025 – 2026

The part of my work that doesn't fit the usual “AI engineer” label. As Firmware & Software Engineer at Tecniplast I built embedded firmware for high-precision laboratory equipment, owning the lifecycle from architecture through testing to deployment, and connected IoT lab devices to cloud analytics for real-time monitoring and control.

At Akaion the same thread continues as hardware orchestration: B2B integrations that let devices, IoT endpoints and machinery be coordinated from the same platform that runs the agents, white-labeled for the client.

In practice it means I can reason about latency, device constraints and failure modes on the equipment itself — not only about the API in front of it.
